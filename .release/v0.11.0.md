# MOEX Fair Price v0.11.0

Minor release adding the first independent calendar-year net-profit model source: fin-vista.

## Added

- Added a dedicated HTML adapter for public fin-vista stock prospect pages.
- Added calendar-year net-profit forecast import from columns explicitly marked as forecast years.
- Added optional dividend forecast import from the same pages.
- Added ruble/kopeck normalization for per-share values.
- Added support for negative net-profit forecasts.
- Added optional ticker-to-fin-vista slug aliases through `FINVISTA_TICKER_ALIASES_JSON`.
- Added scheduler integration to the existing forecast worker.
- Added automatic creation of a separate `fin-vista (модель)` table from the primary ticker universe.

## Semantics and safety

- fin-vista is labelled as a model, not as an analyst: the source states that its indicators and forecasts are calculated automatically and are not manually reviewed.
- The source is disabled by default with `FINVISTA_ENABLED=false`, so upgrading does not silently change the existing consensus.
- Enable it explicitly with `FINVISTA_ENABLED=true` after reviewing the source role in your consensus.
- Net profit is accepted only when the page explicitly states that financial amounts are in billions of rubles.
- Only columns explicitly marked as forecast years are imported; historical and auxiliary `2026*`/`2027*` tables are ignored.
- If unit semantics or the forecast profit row cannot be determined, that ticker fails closed and no values are written for it.
- Missing ticker pages fail per instrument and do not block synchronization of the remaining universe.

## Compatibility

- No database migration.
- No API contract change.
- No change to Arsagera, DOHOD, Published Sheets, consensus formulas, Watchlist scoring or volume monitoring.
- Existing Docker Compose service names and deployment commands remain unchanged.

## Verification

- Unit tests cover calendar-year parsing, thousands separators, negative profits, optional dividends, kopeck-to-ruble conversion, forecast-column discrimination and alias validation.
- Existing backend, browser, Compose and Docker image CI remain the release gate.
