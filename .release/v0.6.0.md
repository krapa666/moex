# MOEX Fair Price v0.6.0

Minor release separating the consensus price view from dividend-inclusive total return.

## Added

- The Analytics consensus now shows **«Ценовой потенциал»**:
  - `(MedianTarget / CurrentPrice - 1) × 100%`;
  - calculated from the same-year median target and current market price;
  - explicitly excludes dividends.
- Added **«Целей выше рынка»** as an exact `N/M` count of comparable target prices strictly above the current market price.
- The existing **«Медианная доходность»** remains separate and continues to use backend `upside_percent`, including remaining dividends to the forecast horizon.
- The UI explains the difference between price-only potential and full expected return directly in the consensus notes.

## Safety and semantics

- Analysts on another forecast year remain excluded by the existing same-year consensus rule.
- If a valid positive current market price is unavailable, both new price-only metrics show as unavailable instead of inferring a substitute.
- Guest analyst-name masking remains unchanged.

## Compatibility

- No API route or response-schema changes.
- No database or migration changes.
- No changes to Arsagera sync, volume monitor, Watchlist score, dividend semantics or Compose topology.

## Verification

- Playwright verifies neutral `0.0%` median price gap and `1/2` targets above market for SBER.
- Playwright verifies positive `+14.8%` price gap and `1/1` target above market for single-target LKOH.
- Guest and 375 px mobile contracts remain covered.
