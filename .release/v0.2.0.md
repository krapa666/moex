# MOEX Fair Price v0.2.0

Minor release adding the first dedicated current-consensus view to Analytics.

## Added

- Added **«Консенсус аналитиков»** to `/analytics/?ticker=...` using the existing ticker-comparison API.
- The panel shows the current target-price minimum, median, maximum and market price.
- Added a compact target range with one marker per comparable analyst and an exact analyst/target list below it.
- Consensus is calculated only for one common forecast horizon: the primary table's `forecast_start_year`.
- Analysts whose current target belongs to another forecast year are excluded from min/median/max instead of mixing horizons; the panel shows used targets versus total tables.
- The current consensus remains all-analyst even when the revision-history filter is narrowed to one analyst.
- Added dedicated Analytics documentation in `docs/analytics.md`.

## Compatibility

- No backend, database, Arsagera synchronization or API contract changes.
- Existing `/api/ticker-comparison` remains the single data source for current cross-analyst comparison.
- Existing forecast-history and chart behavior is unchanged.

## Verification

- Playwright covers the exact min/median/max values, same-year exclusion, analyst target list and mobile page-width contract.
- Existing backend, frontend syntax, Compose, browser and image-build CI remain required before merge.

## Production check

After deploying `v0.2.0`, open a ticker with at least two analyst estimates, for example:

```text
https://moex.junnylab.ru/analytics/?ticker=SBER
```

Verify that the consensus year matches the primary table's first forecast year and that the number of comparable targets shown in the panel is expected for the current analyst tables.
