# MOEX Fair Price v0.28.0

Minor release adding an operational Actual Results Corpus Worklist for the current production primary universe.

## Added

- Added local-only JSON worklist endpoint:
  - `GET /api/analytics/actual-net-profits/backfill/worklist`
- Added local-only CSV worklist endpoint:
  - `GET /api/analytics/actual-net-profits/backfill/worklist.csv`
- Worklist is derived from the current primary table in the database, not from a hard-coded ticker list.
- Added selectable completed-year depth (`1..20` through API; `3/5/7/10` in UI).
- Added operational corpus summary:
  - current primary ticker count;
  - requested ticker/year pairs;
  - already stored facts;
  - missing facts;
  - fill percentage;
  - per-year breakdown.
- CSV contains only missing `ticker × fiscal_year` pairs and exactly matches the v0.27 backfill-import contract.
- Fact and provenance fields in generated CSV are intentionally blank; no synthetic or demo values are inserted.
- Added local Analytics worklist controls and download action.
- Added backend and Playwright tests.
- Added `docs/actual-result-worklist.md`.

## Methodology boundary

The worklist is an **operational current-universe fill list**, not historical accuracy coverage.

Its denominator is:

```text
current primary universe × selected completed fiscal years
```

It must not be interpreted as proof that every ticker/year was historically listed or is methodologically comparable. Newly created companies, reorganizations and IPOs may leave legitimately unresolved rows. Missing history must never be fabricated merely to reach 100% fill.

The existing `/api/analytics/actual-net-profits/coverage` remains the evidence-oriented metric whose denominator is built from real historical forecast pairs available before the selected cutoff.

## Safety

- Worklist endpoints are local-only.
- Current/future fiscal years are rejected.
- Worklist windows cannot start before fiscal year 2000, matching the backfill importer contract.
- Existing canonical facts are never modified by worklist generation.
- v0.27 preview/apply protections remain unchanged.

## Production boundary

Unchanged:

- production median consensus;
- source weights;
- controlled canary scope and limits;
- auto-promotion;
- forecast parsers and source cadence;
- Watchlist;
- volume monitor;
- MOEX CCI configuration.

## Database and configuration

- Database migration required: **no**.
- Existing `stock_rows`, `analyst_tables` and `actual_net_profits` tables are reused read-only by worklist generation.
- Schema head remains `0024_canary_evidence`.
- Mandatory `.env` changes: **no**.
