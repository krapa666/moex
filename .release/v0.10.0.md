# MOEX Fair Price v0.10.0

Minor release adding the first independent non-Google-Sheets forecast adapter: UK DOHOD dividend forecasts.

## Added

- Added built-in synchronization with the public UK DOHOD dividend analytics catalogue.
- Added automatic MOEX ticker -> DOHOD page discovery from the public catalogue.
- Added optional `DOHOD_TICKER_ALIASES_JSON` for exceptional ticker/slug mismatches.
- Added full-calendar-year dividend reconstruction from individual payment rows:
  - multiple payments in one year are summed;
  - current-year actual/announced/forecast payments are kept together as the full annual forecast;
  - future forecast payments are grouped by the registry-date calendar year.
- Added automatic `ДОХОДЪ` analyst-table provisioning from the primary ticker universe.
- Added scheduler integration to the existing `arsagera-worker` process.
- Added focused parser, catalogue, alias and multi-payment tests.

## Semantics

- DOHOD is intentionally a partial source in v0.10.0: it updates dividends only.
- DOHOD's public `Прогноз прибыли в след. 12m` value is not copied into `net_profit_year_map` because it is a rolling 12-month metric, while MOEX Fair Price stores calendar-year profit forecasts.
- Missing annual profit data therefore cannot distort fair-price or price-consensus calculations.
- The generic source engine preserves fields that a partial source does not provide.

## Defaults

- `DOHOD_ENABLED=true`
- `DOHOD_ANALYST_NAME=ДОХОДЪ`
- sync every 6 hours
- run once on worker startup

Set `DOHOD_ENABLED=false` to disable this source.

## Compatibility

- No database migration.
- No API contract change.
- No changes to Arsagera parsing, consensus formulas, Watchlist scoring or volume monitoring.
- Existing Compose service names and deployment commands remain unchanged.

## Verification

- Unit tests cover ticker catalogue mapping, aliases, annual dividend reconstruction and multiple payments per year.
- Existing backend, browser, Compose and image-build CI remain the release gate.
