# MOEX Fair Price v0.4.0

Minor release adding a return-oriented view to the current Analytics consensus.

## Added

- Added **«Медианная доходность»** to `/analytics/?ticker=...`.
- The value is the median of the existing backend `upside_percent` for analyst targets that already belong to the comparable consensus year.
- Because `upside_percent` is calculated by the backend, the metric keeps the same semantics as the main valuation table and includes remaining dividends through the forecast horizon.
- Added **«Положительных»** as `N/M`, where `N` is the number of comparable forecasts with total return above `0%`, and `M` is the number of comparable forecasts with a calculated `upside_percent`.
- Forecasts on a different year remain excluded from both the price and return consensus.
- A comparable target without `upside_percent` still participates in min/median/max target-price statistics but is excluded from return statistics.
- Positive and negative median return values receive restrained semantic coloring in light and dark themes.

## Compatibility

- No API route or response-schema changes.
- No database or migration changes.
- No Arsagera synchronization or volume-monitor changes.
- Guest-mode analyst-name masking from v0.3.2 is preserved.

## Verification

- Playwright verifies that SBER targets `+23.3%` and `-10.7%` produce a median total return of `+6.3%` and `1/2` positive forecasts.
- A third analyst on the 2027 horizon has `+75%` but remains excluded from the 2026 consensus, proving that return horizons are not mixed.
- Single-target consensus continues to report agreement as insufficient while still showing the available return outlook.
- Guest-mode and 375 px mobile contracts remain covered.
