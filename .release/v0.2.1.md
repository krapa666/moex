# MOEX Fair Price v0.2.1

Patch release aligning backend runtime version metadata with the repository release version.

## Fixed

- FastAPI/OpenAPI metadata from the production entrypoint `app.application:app` now reports the current MOEX Fair Price release version instead of the stale historical value `1.2.0`.
- Added a small packaged-version resolver: source checkouts read the root `VERSION`, while the backend image uses a packaged fallback because its Docker build context is `backend/`.
- CI now verifies that the repository `VERSION`, packaged fallback, resolved application version and FastAPI `app.version` are identical.

## Compatibility

- No API routes, response schemas, database schema, Arsagera synchronization, volume monitoring or frontend behavior changes.
- Docker build contexts and Compose topology are unchanged.

## Verification

- Backend tests import the production application entrypoint and assert that runtime metadata matches `VERSION`.
- Existing full CI and Docker image builds remain required before merge.

## Production check

After deploying `v0.2.1`, verify the OpenAPI metadata from the backend reports version `0.2.1`, for example via `/openapi.json` through the trusted local route.
