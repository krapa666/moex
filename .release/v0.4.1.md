# MOEX Fair Price v0.4.1

Patch release restoring convenient bulk entry of dividend forecasts for local editors.

## Fixed

- Restored the dividend forecast columns for both displayed forecast years in the main `/` valuation table when the client has local edit access.
- The existing `dividends_year1` and `dividends_year2` inputs are shown directly in the table again, so analysts can enter multiple dividend forecasts without opening each stock drawer.
- Direct edits continue to use the existing row autosave and update dividend-yield calculations immediately.
- The **«Подробнее»** drawer remains an alternative editor for the same underlying dividend values.

## Guest behavior

- Internet/guest sessions keep the compact 13-column read-only table.
- Dividend input columns remain hidden for guests.
- Existing calculated dividend yield and total return values remain visible and unchanged.

## Compatibility

- No API, database, migration, Arsagera, volume-monitor or Compose changes.
- No change to `dividend_year_map` semantics: it still stores the full calendar-year dividend forecast, while backend calculations subtract already paid current-year dividends where required.

## Verification

- Playwright verifies that local editors see 15 visible table cells including both dividend inputs.
- Playwright verifies that guest sessions continue to see 13 visible cells and hidden dividend inputs.
- Playwright edits a dividend forecast directly in the table, checks the immediate dividend-yield recalculation, blurs the field and verifies successful autosave.
- Existing desktop layout, drawer editing, sorting, deep links and theme tests remain in the full browser suite.
