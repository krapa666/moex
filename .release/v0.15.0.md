# MOEX Fair Price v0.15.0

Minor release adding a no-lookahead backtest for net-profit consensus aggregation while keeping the production fair-value consensus unchanged.

## Added

- Added `backend/app/consensus_backtest.py`.
- Added out-of-sample comparison of three annual net-profit aggregation methods:
  - median baseline;
  - arithmetic mean;
  - conservative accuracy-weighted mean.
- Added no-lookahead training rules: a source weight for fiscal year `Y` can use only older accuracy samples whose canonical actual result has a known `reported_at` strictly before the target backtest cutoff.
- Added conservative weighting controls:
  - shrinkage to the global historical error prior;
  - minimum effective error floor;
  - bounded relative source score;
  - neutral prior for sources without history.
- Added public summary API:
  - `GET /api/analytics/consensus-backtest`
- Added local-only observation audit API:
  - `GET /api/analytics/consensus-backtest/observations`
- Added Analytics UI table comparing backtest methods on the same snapshot selector as source accuracy.
- Added backend tests for no-lookahead publication timing, shrinkage/weight caps, neutral no-history behavior, integrated forecast-revision/factual data flow and local-only observation access.
- Added browser coverage for both local and internet/read-only Analytics modes.
- Added `docs/consensus-backtest.md` and refreshed README/Analytics/source-accuracy documentation.

## Methodology

For one source with `n` available historical samples:

```text
reliability = n / (n + shrinkage_samples)

effective_error = reliability × source_median_sMAPE
                + (1 - reliability) × global_median_sMAPE
```

The effective error is floored and converted to a relative score against the global reference error. Relative scores are capped before normalization so short or unusually strong/weak history cannot create extreme weights.

Default parameters:

- `min_sources = 2`;
- `shrinkage_samples = 5`;
- `error_floor_percent = 5`;
- `relative_score_cap = 2`.

If no usable historical facts were known at the target cutoff, all sources receive equal scores and the accuracy-weighted method becomes the ordinary arithmetic mean.

## Metrics

All methods are scored on exactly the same eligible `(ticker, fiscal_year)` observations using:

- median and mean sMAPE;
- median and mean absolute error, billion RUB;
- mean bias;
- profit/loss sign accuracy;
- ticker/year/sample coverage.

The API additionally reports sMAPE deltas versus the median baseline. A positive delta means improvement versus median.

## Privacy and access

The public summary contains no analyst/source names and is safe for internet read-only users.

The detailed observation endpoint includes real source forecasts, weights and training sample counts keyed by `analyst_name`, so it requires explicit local scope and cannot be used to bypass internet source-name masking.

## Production consensus

**v0.15.0 does not change the production target-price consensus, fair-value formulas, Watchlist ranking or expected-return calculations.**

The backtest is an evidence layer only. Accuracy-weighted production consensus remains disabled until historical coverage is sufficient and the improvement is stable across companies, years, snapshots and reasonable weighting parameters.
