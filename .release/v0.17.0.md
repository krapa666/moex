# MOEX Fair Price v0.17.0

Minor release adding current shadow accuracy-weighted consensus and an explicit readiness policy for a future production-weighting decision.

## Added

- Added public current shadow consensus API:
  - `GET /api/analytics/shadow-consensus?ticker=SBER`
- Added public readiness API:
  - `GET /api/analytics/consensus-readiness?snapshot=pre_year`
- Existing robustness response now includes the same readiness result in its `readiness` field, so Analytics can render robustness and readiness from one 27-case sweep.
- Added a `Shadow weighted consensus` panel for the currently selected ticker.
- Added a `Readiness к production weighting` panel with explicit `PASS` / `WAIT` gates.

## Shadow weighting

The current shadow target uses the same target year as production consensus: the primary table `forecast_start_year`.

Historical weight horizon is selected according to the current phase of that target year:

- future target year -> `pre_year`;
- current target year before July 1 -> `pre_year`;
- current target year from July 1 -> `mid_year`;
- past target year -> `year_end`.

Historical samples may train a current weight only when:

- their fiscal year is older than the current target year;
- the canonical actual has a known `reported_at`;
- `reported_at` is earlier than the current calculation time.

Weighting keeps the v0.15 defaults:

- `shrinkage_samples = 5`;
- `error_floor_percent = 5`;
- `relative_score_cap = 2`.

If no eligible training history exists, weights are neutral/equal and shadow weighted equals the arithmetic mean.

## Readiness policy

`READY` requires all 11 engineering gates:

- at least 30 historical observations;
- at least 10 tickers;
- at least 3 fiscal years;
- overall median-sMAPE improvement at least `+1.0 pp`;
- positive overall mean-sMAPE improvement;
- at least 60% positive ticker slices;
- at least 66.7% positive year slices;
- at least 80% leave-one-ticker-out preservation;
- at least 80% leave-one-year-out preservation;
- at least 80% positive parameter-grid cases;
- the worst parameter-grid median delta remains above `0 pp`.

These thresholds are an explicit promotion policy, not a claim of statistical significance.

## Privacy

Public shadow/readiness outputs contain only aggregate values. They do not expose:

- real analyst names;
- source-level current forecasts;
- source-level weights.

Duplicate current tables with the same exact `analyst_name` are treated as one source identity, consistent with the current source-accuracy model.

## Production consensus

**v0.17.0 does not promote weighted consensus to production.**

The following remain unchanged:

- production median target price;
- fair-value formulas;
- expected-return calculations;
- Watchlist ranking;
- volume-monitor logic.

Even `READY` only means the documented evidence policy has passed for a snapshot. A separate review and release are required before any production change.

## Database and configuration

- Database migration required: **no**.
- Mandatory `.env` changes: **no**.
- Current schema head remains `0020_actual_source_key`.
- Shadow results are calculated on demand and are not persisted as a separate history in this release.
