# MOEX Fair Price v0.3.0

Minor release adding a transparent analyst-agreement signal to the current Analytics consensus.

## Added

- Added **«Разброс»** to the current analyst consensus on `/analytics/?ticker=...`.
- The metric is calculated only from comparable target prices for the primary table's forecast year:

  ```text
  (MaxTarget - MinTarget) / MedianTarget × 100%
  ```

- Added an explicit **«Согласованность»** category:
  - `≤ 10%` — высокая;
  - `> 10%` and `≤ 25%` — средняя;
  - `> 25%` — низкая.
- With fewer than two comparable targets the UI shows `—` for spread and **«Недостаточно данных»** instead of inferring false agreement.
- The formula and thresholds are shown directly in the Analytics panel and documented in `docs/analytics.md`.
- Added responsive and dark-theme styling for the new consensus KPIs.

## Compatibility

- No API route or response-schema changes.
- No database or migration changes.
- No Arsagera synchronization or volume-monitor changes.
- Existing consensus min/median/max, market price, target range and analyst list remain unchanged.

## Verification

- Playwright verifies the exact spread value and agreement category for a multi-analyst case.
- Playwright verifies that a single comparable target is reported as insufficient data.
- Mobile coverage continues to enforce no horizontal overflow at 375 px.
- Repository/package/FastAPI version consistency remains enforced by backend tests.
