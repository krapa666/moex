# MOEX Fair Price v0.9.0

Minor release introducing pluggable published-Google-Sheets forecast sources.

## Added

- Added a provider-neutral forecast synchronization engine shared by Arsagera and future sources.
- Added configurable Published Google Sheets sources through `FORECAST_SHEETS_SOURCES_JSON`.
- Added per-source ticker-to-sheet aliases for cases where MOEX ticker and workbook tab name differ.
- Added automatic analyst-table provisioning for configured external sources:
  - creates the analyst table when it does not exist;
  - copies the current primary-table ticker universe and shared company fields;
  - leaves forecast fields empty until the source sync succeeds.
- Added isolated per-ticker fetch/parse failures and shared future-year merge semantics for every source.

## Compatibility

- Arsagera keeps its existing `ARSAGERA_*` configuration and sync behavior.
- The Compose service remains named `arsagera-worker` to preserve deployment compatibility.
- No database migration or API contract change.
- No change to consensus, dividend, Watchlist or volume-monitor formulas.
- Extra published-sheet sources are opt-in; the default `FORECAST_SHEETS_SOURCES_JSON=[]` changes no production data.

## Operational notes

- Additional sources must be public Google Sheets workbooks published to the web.
- Workbook tabs are expected to be named by ticker or mapped through `sheet_aliases`.
- The generic parser intentionally fails closed on unsupported or ambiguous layouts; a dedicated adapter is required for structurally different sources.
- Source-only tickers are not added to the application's primary universe automatically.
- Release publishing now resolves notes from the repository `VERSION`, so normal merge commits are supported without depending on merge-diff behavior.

See `docs/forecast-sources.md` for configuration and parser assumptions.

## Verification

- Added tests for external-source JSON validation and alias normalization.
- Added async coverage for alias-to-GID discovery.
- Added database coverage for automatic analyst-table creation and primary-universe cloning.
- Existing Arsagera merge helpers remain import-compatible.
