# MOEX Fair Price v0.5.0

Minor release making the current analyst consensus more transparent by showing each analyst's own expected total return next to the target price.

## Added

- Each comparable analyst row in `/analytics/?ticker=...` now shows both:
  - target price;
  - full expected return (`upside_percent`) for the same forecast year.
- Positive per-analyst returns are highlighted in green, negative values in red, zero or unavailable values remain neutral.
- The rows use the same backend-calculated total return that feeds the existing `Медианная доходность` and `Положительных` aggregate indicators.
- Analysts on another forecast horizon remain excluded exactly as before.
- Guest-mode masking remains unchanged: internet users see `Аналитик N` labels but the same public price/return values.

## Compatibility

- No API route or response-schema changes.
- No database or migration changes.
- No changes to Arsagera, volume monitor, dividend semantics or Compose topology.

## Verification

- Playwright verifies `+23.3%` for the positive SBER analyst and `-10.7%` for the negative analyst.
- The same test verifies the aggregate median `+6.3%` and `1/2` positive forecasts.
- Guest-mode tests verify that individual returns remain visible while real analyst names stay masked.
- Single-target and 375 px mobile contracts remain covered.
