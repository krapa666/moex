# MOEX Fair Price v0.8.0

Minor release adding latest-movement deltas to the historical analyst consensus.

## Added

- Added **«Изм. медианы»** to the `Динамика консенсуса` summary:
  - compares the latest median target with the previous aggregate state of the same forecast year;
  - shows the absolute change in rubles and the relative percentage change;
  - uses `↑`, `↓` or `→` to show direction.
- Added **«Изм. разброса»**:
  - compares the latest `SpreadPercent` with the previous aggregate state of the same forecast year;
  - reports the change in percentage points (`п.п.`), not as a second-order relative percent.
- Forecast-year boundaries are fail-closed: a new forecast year starts with `—` deltas until another aggregate point exists for that same year.
- Spread movement is shown only when spread exists in both comparable points.

## Semantics

- A positive median delta means the reconstructed analyst-consensus target moved higher.
- A negative median delta means it moved lower.
- A positive spread delta means analyst targets moved farther apart.
- A negative spread delta means the target range narrowed.
- The feature reuses the `v0.7.0` reconstructed consensus points; no additional API request or historical source is introduced.

## Compatibility

- No database or migration changes.
- No API route or response-schema changes.
- No changes to current-consensus formulas, Arsagera sync, volume monitor, Watchlist score, dividend semantics or Compose topology.
- Guest-mode privacy remains unchanged because historical consensus still renders no analyst names.

## Verification

- Playwright verifies SBER latest movement from the reconstructed series:
  - median `288.75 ₽ -> 298.75 ₽` = `↑ +10 ₽ · +3.5%`;
  - spread about `28.6% -> 34.3%` = `↑ +5.7 п.п.`.
- Playwright verifies that a forecast-year change does not compare the new horizon with the previous year.
- Analyst-filter independence, guest privacy and 375 px mobile no-overflow remain covered.
