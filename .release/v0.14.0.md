# MOEX Fair Price v0.14.0

Minor release adding a controlled automatic source for factual annual net profit used by forecast-accuracy scoring.

## Added

- Added a generic actual-result synchronization engine separate from forecast-source synchronization.
- Added `source_key` ownership for canonical `actual_net_profits` records.
- Existing/manual facts are backfilled as `manual`.
- Added an optional MOEX Corporate Information Center (CCI) adapter for short IFRS reports.
- Public MOEX ISS maps exchange ticker to issuer INN; CCI then resolves the exact company by INN.
- Added annual-report selection using `YYYYY4Q` period codes.
- Added explicit RUB-only and scale-normalization rules.
- Added owner-attributable net-profit extraction for forecast accuracy.
- Added restatement handling: for a fiscal year, the later CCI publication is preferred.
- Added public safe integration status API:
  - `GET /api/analytics/actual-net-profits/sync-status`
- Added local-only manual synchronization API:
  - `POST /api/analytics/actual-net-profits/sync`
- Added local Analytics controls showing whether CCI is disabled, unconfigured or ready, plus a manual sync button when available.
- Added scheduled CCI synchronization to the existing forecast worker without changing its Compose service name.
- Added parser, ownership, API and browser tests.
- Added `docs/actual-result-sources.md`.

## Data integrity

Automatic CCI import is fail-closed. A fact is accepted only when the adapter can establish:

1. an exact issuer mapping by INN;
2. an annual IFRS period;
3. RUB currency;
4. a known unit scale;
5. exactly one owner/shareholder-attributable net-profit field;
6. a finite numeric value.

No automatic FX conversion, RSBU fallback, PDF OCR or company-name fuzzy matching is used.

## Manual override semantics

- Manual facts use `source_key=manual`.
- CCI facts use `source_key=moex-cci`.
- An automatic source may update only a fact that it owns.
- A manual edit of a previously imported CCI fact changes ownership to `manual` and protects it from later CCI synchronization.

## Licensing and configuration

MOEX CCI is a separately licensed service. The integration is disabled by default and no credentials are bundled with the application.

Optional local `.env` variables:

```dotenv
MOEX_CCI_ACTUALS_ENABLED=true
MOEX_CCI_USERNAME=<login>
MOEX_CCI_PASSWORD=<password>
MOEX_CCI_ACTUALS_SYNC_INTERVAL_HOURS=24
MOEX_CCI_ACTUALS_RUN_ON_STARTUP=false
MOEX_CCI_ACTUALS_YEARS_BACK=5
MOEX_CCI_TIMEOUT_SECONDS=30
MOEX_CCI_CONCURRENCY=4
```

A normal deployment requires no new environment variables if CCI synchronization remains disabled.
