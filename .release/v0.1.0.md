Первый формальный GitHub Release проекта MOEX Fair Price.

## Главное

- сравнение прогнозной справедливой цены акций Московской биржи по нескольким аналитикам;
- автоматическое получение текущих котировок через MOEX ISS;
- расчёт прогнозной цены через чистую прибыль, число акций и исторический P/E;
- расчёт полной ожидаемой доходности с дивидендами;
- монитор оборотов всех обыкновенных и привилегированных акций TQBR;
- Watchlist с прозрачным приоритетным score 0–100 и разбором факторов;
- PostgreSQL, резервные копии и развёртывание через Docker Compose.

## Автоматическая синхронизация Арсагеры

Добавлен отдельный `arsagera-worker`.

Он:

- работает только с уже существующими тикерами таблицы аналитика `Арсагера`;
- автоматически находит соответствующий опубликованный лист Google Sheets по тикеру;
- читает самый свежий квартальный блок прогноза, не смешивая его с историческими ревизиями ниже по листу;
- импортирует прогноз чистой прибыли по календарным годам;
- импортирует полный прогноз дивидендов на акцию по календарным годам;
- не перезаписывает прошлые годы;
- не создаёт новую ревизию, если значения не изменились;
- помечает автоматические изменения как `changed_by=arsagera-sync`;
- работает fail-closed: неоднозначные или неполные данные не затирают уже сохранённый прогноз.

По умолчанию синхронизация выполняется при старте worker и затем каждые 6 часов. Параметры можно изменить через:

- `ARSAGERA_ANALYST_NAME`;
- `ARSAGERA_SYNC_INTERVAL_HOURS`;
- `ARSAGERA_SYNC_CONCURRENCY`;
- `ARSAGERA_RUN_ON_STARTUP`.

## Полные годовые дивиденды

`dividend_year_map` теперь однозначно трактуется как полный прогноз дивидендов за календарный год.

Для текущего года backend получает из MOEX ISS уже прошедшие фактические выплаты и вычитает их при расчёте полной доходности. Поэтому вручную уменьшать годовой прогноз после каждой выплаты больше не требуется.

Для будущих календарных лет прогноз дивиденда учитывается полностью.

## Watchlist priority score

Watchlist получил детерминированный score 0–100 с видимым разбором факторов. Сортировка по приоритету сохраняется в существующем представлении, а широкая таблица остаётся корректной на мобильных экранах.

## Монитор оборотов

В составе приложения остаётся отдельный `volume-worker` с:

- историей последних торговых сессий;
- регулируемым периодом среднего оборота;
- обнаружением аномального оборота;
- областью уведомлений IMOEX/TQBR;
- email-уведомлениями и ручным запуском сбора.

## Развёртывание и обновление

Для существующей установки рекомендуемый порядок:

```bash
git pull --ff-only
./scripts/compose-up.sh
docker compose ps
```

Новые параметры Арсагеры необязательно добавлять в существующий `.env`: в `docker-compose.yml` предусмотрены рабочие значения по умолчанию.

После обновления полезно проверить:

```bash
curl http://127.0.0.1:18000/api/live
curl http://127.0.0.1:18000/api/health
docker compose logs --tail=100 arsagera-worker
```
