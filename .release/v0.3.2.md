# MOEX Fair Price v0.3.2

Patch release restoring guest-mode analyst-name masking across `/analytics/`.

## Fixed

- Analytics now follows the same access-mode contract as the main valuation page.
- Local-network clients (`/api/auth/me` -> `is_admin: true`) continue to see real analyst/table names.
- Internet/guest clients see only `Аналитик 1`, `Аналитик 2`, etc.
- If access-mode detection fails, Analytics fails closed and uses guest labels.
- Masking is applied consistently to:
  - the analyst selector;
  - current consensus targets and marker tooltips;
  - today's forecast revisions;
  - forecast revision chronology;
  - chart legend and point tooltips.

## Implementation

- Added a shared `frontend/analytics/access.js` helper that loads `/api/auth/me` and `/api/tables` once and exposes a single analyst-name display policy to all Analytics components.
- Historical revisions map `table_id` back to current `table_number` before generating guest labels.

## Verification

- Existing Analytics E2E scenarios run in explicit local-admin mode and continue to verify real analyst names.
- Added a guest-mode regression test that verifies the analyst selector and consensus do not render real internal analyst names.
- Full frontend syntax, Playwright, backend and image-build CI remain required before merge.

## Compatibility

- No database or migration changes.
- No changes to forecast calculations, consensus math, Arsagera synchronization, volume monitoring or Compose topology.
