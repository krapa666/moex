Hotfix релиза `v0.1.0` для запуска backend.

## Исправлено

- устранён циклический импорт `forecast_history ↔ models`, из-за которого production backend падал при старте через `app.application` с `ImportError: cannot import name 'ForecastRevision' from partially initialized module 'app.forecast_history'`;
- сохранена регистрация модели `ForecastRevision` для SQLAlchemy/Alembic;
- добавлен regression test, который импортирует `app.application` в отдельном чистом Python-процессе и воспроизводит именно production-порядок импортов.

Изменений схемы БД поверх `v0.1.0` этот hotfix не добавляет.

## Обновление с v0.1.0

```bash
git fetch origin --tags
git switch --detach v0.1.1
./scripts/compose-up.sh
```

После запуска рекомендуется проверить:

```bash
docker compose ps
curl -fsS http://127.0.0.1:18000/api/live ; echo
curl -fsS http://127.0.0.1:18000/api/health ; echo
docker compose logs --tail=100 backend
docker compose logs --tail=200 arsagera-worker
```
