# MOEX Fair Price v0.1.2

Patch release for production Arsagera synchronization.

## Fixed

- Added exact published-sheet aliases for preferred-share tickers whose Arsagera workbook tabs use the base ticker name:
  - `BANEP` → `BANE`
  - `SNGSP` → `SNGS`
  - `TRNFP` → `TRNF`
- Dividend parsing now resolves explicit share-class rows deterministically:
  - ordinary tickers select `ао`;
  - preferred tickers ending in `P` select `ап`.
- `RTKM` and `TATN` no longer fail with `неоднозначная строка дивидендов` when both `ао` and `ап` rows are present in the latest Arsagera forecast block.
- Existing fail-closed behavior remains: ambiguous or missing source data is skipped without clearing stored forecasts.

## Release discipline

- Added canonical `VERSION` file.
- Added documented SemVer and release policy in `docs/release-process.md`.
- Releases are published only from commits merged into `main`.
- Release automation validates that the `.release/vX.Y.Z.md` filename matches `VERSION`.
- CI verifies that the repository version is valid SemVer and has matching release notes.

## Production verification

After updating to `v0.1.2`, verify:

```bash
docker compose ps
docker compose logs --since=15m arsagera-worker \
  | grep -E 'Arsagera sync:|Arsagera sync skipped|Initial Arsagera'
```

Expected successful synchronization for the current 54-ticker Arsagera table is `mapped=54` and `skipped=0` if the upstream workbook structure has not changed.
