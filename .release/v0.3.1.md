# MOEX Fair Price v0.3.1

Patch release stabilizing the Watchlist mobile browser contract after the v0.3.0 release.

## Fixed

- Fixed a race in the Watchlist mobile Playwright test: layout measurements could run before the asynchronous Watchlist rows were rendered, so the hidden table wrapper reported `0` width and produced a false CI failure.
- The test now waits for the SBER row and the table wrapper to be visible before measuring table and page overflow.

## Compatibility

- No user-facing Watchlist behavior changes.
- No Analytics consensus changes from v0.3.0.
- No API, database, Arsagera synchronization, volume-monitor, Compose or Docker topology changes.

## Verification

- The mobile Watchlist test still verifies that the table itself horizontally scrolls inside its wrapper while the page does not overflow.
- The score explanation is still opened and rechecked against the page-width contract.
- Full backend, frontend/scripts, Playwright and image-build CI remain required before merge.
