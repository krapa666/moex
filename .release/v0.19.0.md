# MOEX Fair Price v0.19.0

Minor release adding a global forward shadow-drift overview across the primary forecast universe while keeping production consensus unchanged.

## Added

- Added public aggregate API:
  - `GET /api/analytics/shadow-consensus/overview?days=30`
- Added Analytics global monitoring panel rendered without selecting a ticker.
- Added status summary and coverage metrics across the current primary-table universe.
- Added filters for `ALERT + WATCH`, individual statuses and accumulation state.
- Added monitoring windows 7 / 30 / 90 / 180 days.
- Added direct links from overview rows to the ticker-level Analytics view.

## Overview semantics

The overview does **not** introduce a second drift algorithm.

Every ticker uses the same classifier and thresholds as:

```http
GET /api/analytics/shadow-consensus/drift?ticker=SBER
```

Default order:

```text
ALERT → WATCH → STABLE → insufficient
```

Within a status, larger absolute current weighted-vs-median divergence is shown first.

The universe is the current primary analyst table (lowest `sort_order`, then `id`). A primary-universe ticker without forward shadow history remains visible as:

```text
status = insufficient
reason = no_history
```

This prevents weak monitoring coverage from looking like a clean `STABLE` universe.

## Coverage summary

The API returns:

- total primary-universe tickers;
- tickers with at least one shadow-history snapshot;
- tickers with enough history for classification;
- `ALERT / WATCH / STABLE / insufficient` counts;
- `actionable_tickers = ALERT + WATCH`;
- history coverage percentage;
- classified coverage percentage;
- the per-ticker drift items.

## Query efficiency

Global monitoring avoids an N+1 database pattern.

Backend loads:

1. the current primary-table universe;
2. the latest snapshot for all universe tickers in one grouped query;
3. the selected monitoring-window snapshots in one query.

It then applies the existing drift policy per ticker in memory.

## Privacy / access

The global overview is safe for public read-only mode.

It exposes only:

- MOEX ticker;
- target year;
- aggregate drift metrics;
- operational status/reasons;
- monitoring coverage.

It does **not** expose analyst names, source-level forecasts or source-level weights.

## Production boundary

**v0.19.0 does not promote weighted consensus to production.**

Unchanged:

- production median target price;
- fair-value formulas;
- expected-return calculations;
- Watchlist ranking;
- volume-monitor logic;
- weighting defaults and readiness policy.

The global overview is an observability layer for forward evidence accumulation.

## Database and configuration

- Database migration required: **no**.
- Schema head remains `0021_shadow_consensus_snapshots`.
- Mandatory `.env` changes: **no**.
- Existing v0.18.0 `SHADOW_HISTORY_*` settings remain valid.
