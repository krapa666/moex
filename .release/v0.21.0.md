# MOEX Fair Price v0.21.0

Minor release adding a read-only Production Impact Simulator and Promotion Decision Dashboard for evaluating a future median-to-weighted consensus promotion without changing production behavior.

## Added

- Added public aggregate impact API:
  - `GET /api/analytics/production-impact?top_n=10&history_days=30`
- Added public promotion-only API:
  - `GET /api/analytics/promotion-dossier?top_n=10&history_days=30`
- Added portfolio comparison of median vs shadow weighted target prices and full expected returns.
- Added expected-return rank changes, Spearman rank correlation and Top-N overlap/turnover.
- Added expected-return sign-flip monitoring.
- Added hypothetical consensus-driven Watchlist score sensitivity using the existing 60/25/15 score policy.
- Added a 10-gate promotion dossier with `NOT_READY`, `OBSERVE` and `READY_FOR_MANUAL_PROMOTION` states.
- Added a global Analytics dashboard with Top-10 / Top-20 and 30 / 90 / 180 day controls.
- Added backend unit/API tests and Playwright coverage.
- Added `docs/production-impact.md` and updated the existing Analytics/shadow documentation.

## Methodology

The simulator isolates the aggregation change.

The weighted scenario changes only the price-target layer. The dividend component implied by the median baseline full return is held constant:

```text
median dividend layer
        +
weighted price potential
        =
weighted simulated full return
```

This avoids testing a new consensus aggregator and a different dividend model at the same time.

## Current Watchlist boundary

The existing `/watchlist/` uses primary-table row values, not median consensus values.

Therefore `median_watchlist_score` / `weighted_watchlist_score` in this release are explicitly **hypothetical consensus-driven sensitivity metrics** using the same score formula as the current Watchlist. They do not replace or mutate the production Watchlist.

## Promotion policy

The dashboard combines historical, forward and impact evidence.

Required gates:

```text
historical readiness             11/11 PASS
comparable impact coverage       >= 70%
Spearman rank correlation        >= 0.90
Top-N overlap                    >= 80%
expected-return sign flips       <= 10%
mean abs Watchlist score delta   <= 10 points
forward classified coverage      >= 80%
forward ALERT tickers             0
forward WATCH + ALERT            <= 20% classified
median forward observation span  >= 7 days
```

Statuses:

```text
NOT_READY
OBSERVE
READY_FOR_MANUAL_PROMOTION
```

`READY_FOR_MANUAL_PROMOTION` is informational only. It does not toggle or persist any production setting.

## Privacy

The new public endpoints expose only aggregate/ticker-level scenario metrics and policy results.

They do not expose:

- analyst/source identities;
- source-level forecasts;
- source-level weights;
- private notification/SMTP data.

## Database and configuration

- Database migration required: **no**.
- Schema head remains `0022_shadow_drift_notifications`.
- Mandatory `.env` changes: **no**.

## Production boundary

**v0.21.0 does not promote weighted consensus to production.**

Unchanged:

- production median consensus;
- primary-table fair-value calculations;
- current Watchlist behavior;
- expected-return values persisted in `stock_rows`;
- weighting defaults;
- readiness policy;
- drift thresholds;
- shadow notification state machine.

The next promotion step, if evidence is sufficient, must be an explicit controlled/canary release with rollback to median.
