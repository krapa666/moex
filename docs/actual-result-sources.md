# Источники фактических финансовых результатов

Начиная с v0.14.0 приложение умеет автоматически наполнять канонический реестр `actual_net_profits`, который используется для исторического сравнения прогнозов с фактом.

## Почему источник факта отделён от источников прогнозов

Прогноз аналитика никогда не является фактом. Для расчёта точности нужны опубликованные финансовые результаты эмитента с понятной методологией, валютой, периодом и provenance.

Поэтому автоматический импорт фактов реализован отдельным интерфейсом и не переиспользует Arsagera, DOHOD, fin-vista или Published Sheets.

## MOEX Corporate Information Center

Встроенный автоматический адаптер использует MOEX Corporate Information Center (CCI / ЦКИ):

- стандартный публичный MOEX ISS используется только для сопоставления биржевого тикера с ИНН эмитента;
- CCI ищет компанию по точному ИНН;
- далее загружается `msfo-short` — краткая МСФО;
- рассматриваются только годовые периоды с кодом `YYYYY4Q`;
- принимаются только отчёты в российских рублях;
- значение приводится к млрд ₽ по явно указанному CCI масштабу;
- из отчёта выбирается только чистая прибыль, относимая к собственникам/акционерам;
- общая чистая прибыль после налога не используется как неявный fallback;
- при нескольких публикациях одного года выбирается более поздняя публикация, что позволяет учитывать рестейтмент.

### Почему используется прибыль собственников

Fair-value модель приложения оценивает акционерный капитал. Поэтому для проверки прогнозов используется прибыль, относимая к собственникам/акционерам материнской компании, а не прибыль группы до распределения на неконтролирующие доли.

Если в ответе CCI нет однозначного owner-attributable показателя, запись не создаётся.

## Лицензирование и доступ

MOEX CCI является отдельным лицензируемым сервисом Московской биржи. Подписка и учётные данные не входят в приложение.

Интеграция по умолчанию выключена:

```dotenv
MOEX_CCI_ACTUALS_ENABLED=false
```

Для включения нужны действующие данные MOEX Passport/CCI в локальном `.env`:

```dotenv
MOEX_CCI_ACTUALS_ENABLED=true
MOEX_CCI_USERNAME=<login>
MOEX_CCI_PASSWORD=<password>
MOEX_CCI_ACTUALS_SYNC_INTERVAL_HOURS=24
MOEX_CCI_ACTUALS_RUN_ON_STARTUP=false
MOEX_CCI_ACTUALS_YEARS_BACK=5
MOEX_CCI_TIMEOUT_SECONDS=30
MOEX_CCI_CONCURRENCY=4
```

`.env.example` содержит только пустые placeholders для credentials. **Реальные** логины, пароли и другие секретные значения нельзя добавлять в `.env.example`, Git или release notes.

## Приоритет ручных данных

Каждый факт имеет `source_key`.

Встроенные значения:

- `manual` — запись создана или отредактирована вручную;
- `moex-cci` — запись принадлежит автоматической синхронизации MOEX CCI.

Автоматический источник может обновлять только запись со своим `source_key`. Если для той же пары `ticker + fiscal_year` уже существует ручной факт, автоматическая синхронизация его не перезаписывает и возвращает запись в `records_protected/errors`.

Если администратор вручную исправляет ранее импортированный CCI-факт через интерфейс Analytics, его `source_key` меняется на `manual`. После этого ручное значение становится защищённым от следующих CCI-запусков.

## Fail-closed правила

Факт не импортируется, если невозможно однозначно установить хотя бы одно из условий:

1. точный эмитент по ИНН;
2. годовой период;
3. валюта RUB;
4. известный масштаб единиц;
5. единственный owner-attributable net-profit показатель;
6. конечное числовое значение.

Приложение намеренно не выполняет:

- конвертацию иностранной валюты;
- замену МСФО на РСБУ;
- OCR PDF;
- подбор похожего эмитента по названию;
- использование общей прибыли группы вместо прибыли собственников.

Это снижает покрытие, но защищает рейтинг аналитиков от методологически неверных фактов.

## API

Безопасный статус интеграции:

```http
GET /api/analytics/actual-net-profits/sync-status
```

Он возвращает только `enabled`, `configured`, периодичность и глубину истории. Логин и пароль не возвращаются.

Локальный ручной запуск:

```http
POST /api/analytics/actual-net-profits/sync
```

Доступен только при `X-Moex-Access-Scope: local` и возвращает количество найденных, созданных, обновлённых, неизменившихся и защищённых записей, а также ошибки по тикерам.

Существующий список фактов:

```http
GET /api/analytics/actual-net-profits
```

теперь дополнительно возвращает `source_key`.

## Планировщик

При `MOEX_CCI_ACTUALS_ENABLED=true` и заполненных credentials существующий `arsagera-worker` также планирует задачу `moex-cci-actual-result-sync`.

Имя Compose-сервиса намеренно не менялось, чтобы не ломать текущие deployment/runbook команды.

По умолчанию:

- интервал — 24 часа;
- запуск сразу при старте — выключен;
- глубина — 5 лет.

## Связь с рейтингом точности

После появления новых фактов уже существующий scorer автоматически пересчитывает пары `прогноз → факт` при следующем запросе `/api/analytics/source-accuracy`.

v0.14.x не включает accuracy-weighted consensus. Автоматическое наполнение фактов только увеличивает доказательную базу для будущего backtest весов.
