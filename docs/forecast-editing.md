# Редактирование прогнозов

Раздел `/` используется для ввода и просмотра прогнозов аналитиков.

## Локальный режим

Если `/api/auth/me` определяет клиента как `local-network` (`is_admin = true`), основная таблица остаётся редактируемой.

Для каждого из двух отображаемых прогнозных лет прямо в таблице доступны поля:

- прогноз чистой прибыли;
- прогноз дивидендов, ₽ на акцию.

Колонки дивидендов показываются рядом со справедливой ценой и дивидендной доходностью соответствующего года. Значение можно вводить прямо в строке бумаги; используется тот же существующий autosave, что и для прогноза чистой прибыли.

`dividend_year_map` хранит полный прогноз дивидендов за календарный год. Для текущего календарного года backend самостоятельно вычитает уже прошедшие фактические выплаты при расчёте полной доходности. Вручную уменьшать прогноз после фактической выплаты не нужно.

Карточка **«Подробнее»** остаётся альтернативным способом изменить дивидендный прогноз одной бумаги: её поля синхронизированы с теми же `dividends_year1` / `dividends_year2` и `dividend_year_map`.

## Гостевой режим

Для интернет-клиента (`guest`, `is_admin = false`) таблица остаётся компактной и только для чтения:

- прямые колонки ввода дивидендов скрыты;
- прогнозные значения продолжают участвовать в дивидендной и полной доходности;
- карточка акции показывает данные без возможности редактирования.

Так массовый ввод остаётся удобным в доверенной локальной сети, а публичный интерфейс не перегружается служебными полями редактирования.
